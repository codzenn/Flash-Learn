# Flash Learn

Flash Learn is a polished flashcard study app built with React and Vite. It helps learners review JavaScript concepts through an elegant, interactive experience with flipping cards, progress tracking, and a modern interface. You can try it out here: https://flash-learn-liart.vercel.app

## ✨ Features

- Interactive flashcards with a flip animation
- Clear progress indicator and card counter
- Clean, modern UI designed for focused study
- Smooth navigation between questions and answers
- Lightweight React-based architecture for fast performance

## 🛠 Tech Stack

- React 19
- Vite
- Tailwind CSS
- lucide-react
- Oxlint

## 🚀 Getting Started

1. Install dependencies:

    ```bash
    pnpm install
    ```

2. Start the development server:

    ```bash
    pnpm dev
    ```

3. Open your browser and visit:
    ```text
    http://localhost:5173
    ```

## 📜 Available Scripts

- `pnpm dev` - Start the local development server
- `pnpm build` - Build the project for production
- `pnpm preview` - Preview the production build locally
- `pnpm lint` - Run the linter
